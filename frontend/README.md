# SIGER - Frontend

React + Vite + Tailwind CSS + React Router.

```bash
cp .env.example .env   # URL del backend
npm install
npm run dev            # http://localhost:5173
```

Estructura de `src/`: `api/` (llamadas al backend), `components/` (layout y UI reutilizable),
`context/` y `hooks/` (sesión), `pages/` (por rol), `routes/`, `utils/`.
